# Student Performance Analysis System

A Python project that analyses student marks using Pandas and NumPy.

## What it does
- Reads student data from students.csv
- Calculates total and average marks
- Assigns grades (A+ to F) and Pass/Fail result
- Shows class summary, subject-wise analysis and top performers
- Saves results in student_results.csv and subject_analysis.csv

## Files
- main.py - runs the program
- functions.py - calculation and grading functions
- students.csv - input data (15 students)

## How to run
1. Install the packages: pip install pandas numpy
2. Keep all files in the same folder
3. Run: python main.py
